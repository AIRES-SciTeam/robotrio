# Drone

## Структура файлов

| Файл | Назначение |
| :--- | :--- |
| `requirements.apt.txt` | Список apt-пакетов, которые устанавливаются в образ `drone`. |
| `requirements.py.txt` | Список Python-пакетов, которые устанавливаются в образ `drone`. |
| `README.md` | Этот файл. |

## Структура папок

| Папка | Назначение |
| :--- | :--- |
| `config` | Конфигурационные файлы запуска. |
| `install` | Скрипты установки необходимых подпрограмм. |
| `run` | Скрипты запуска. |
