# Система управления дроном 

Система разделена на две основные части:

* GCS (Ground Control Station) &mdash; наземная станция управления.
* Onboard &mdash; бортовая система управления.

Протокол связи между компонентами: gRPC + Protobuf.

## 1. GCS

Система контроля состояния дрона с наземной станции управления. Лицо, принимающее решение &mdash; оператор.

Зона ответственности:

* Осуществление связи оператора с дроном. Приём телеметрии и изображений с камер.
* Формирование графического пользовательского интерфейса (GUI).
* Приём и передача команд ручного управления с различных источников (джойстик, клавиатура).

### 1.1 Transport

Модуль, ответсвтенный за формирование protobuf-сообщений и передачу их на дрон.
