# Мир Scene
![Scene](scene.png)

## Описание 

Мир подражает специфическому марсианскому ландшафту и состоит из нескольких моделей.

* `ground` &mdash; основа мира. Площадка создана на основе карты высот `heightmap.png` (8-битное изображение в градации серого) с текстурой `texture.jpg`. `heightmap.xcf` &mdash; файл проекта модели земли в графическом редакторе `GIMP`. Размер площадки &mdash; 128x128 единиц; максимальная высота &mdash; 24 единиц; высота площадок техники &mdash; ~5,7 единиц.

## Запуск

Для запуска мира в симуляторе Gazebo требуется перейти в папку мира:

```sh
cd /robotrio/scene
```
и запустить симулятор командой:
```sh
gz sim scene.world
```
